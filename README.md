# nexo

A calm, local-first, AI-powered workspace that combines a second brain with daily tools - notes, tasks, calendar, email, reading, and code - plus an assistant that plans the day.

## What it does

- **Unified inbox** - work, school, and personal streams in one place
- **AI-powered todo list** - captures tasks, organizes them, and produces daily summaries
- **Personal calendar** - AI time-blocking with Google Calendar and Notion integration
- **Tech digest** - RSS, news, and curated YouTube in a single feed
- **Git dashboard** - unfinished PRs, reviews waiting on you, and "what to build next" suggestions
- **Reading list** - save articles to read later
- **Finance widgets** - read-only glance at your accounts

## Tech stack

- **App** - Next.js 16, React 19, TypeScript
- **Desktop** - Tauri 2
- **Data** - Postgres / PGlite with Drizzle ORM
- **Agent** - Vercel AI SDK with MCP tool integrations
- **Auth** - Better Auth with Google OAuth
- **AI** - DeepSeek API

## Status

Early design and prototype stage. The system is designed and prototyped, not yet implemented; this repo will fill in as pieces land. There is nothing to install or run yet.
